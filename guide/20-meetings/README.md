# Meetings

25 meetings, in the order the semester ran them. Each has an
instructor guide and a student handout in its own directory.

**Planned** is the sum of the stage estimates, and every meeting in the
original was planned longer than its seventy-five minute period. Read the
pacing chapter before trusting any of these numbers.

**Reading** means the meeting assigns an article you will need to supply.
**Tools** means it uses an interactive component; the Demos chapter says
which are publicly hosted and which need an account.
