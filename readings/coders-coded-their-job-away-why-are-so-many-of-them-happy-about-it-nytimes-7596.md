## 1. "things occasionally go haywire."

If you've used Claude Code or similar tools, this will sound familiar. ## 2. ""What is computation — what is coding?""

This is not just a philosophical musing — it's the central question of computer science education right now. If coding becomes primarily about describing intent rather than writing syntax, what should a CS curriculum teach? What skills from this course will matter most?

## 3. "100 percent of Cherny's contributions to the Claude codebase are now written entirely by Claude."

Let that sink in: the person leading development of Claude Code doesn't write code by hand anymore — Claude writes Claude. This is a concrete example of recursive self-improvement, one of the concepts that makes AI researchers both excited and nervous.

## 4. ""Jevons paradox""

You may have already experienced this yourself. When a tool makes something easier — like asking an AI to write code — do you do less of it, or do you attempt projects you never would have tried before? The answer tells you something about which economic model best predicts AI's labor market impact.
